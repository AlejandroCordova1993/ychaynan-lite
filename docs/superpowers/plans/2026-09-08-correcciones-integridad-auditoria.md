# Correcciones de integridad de la auditoría — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Corregir los defectos reproducibles de conservación, acceso y evaluación detectados en la auditoría integral sin ampliar Yachayñan Lite con dashboard, exportación, autoría IA o seguimiento longitudinal.

**Architecture:** Las reglas deterministas se concentran en funciones puras compartidas y en RPC/migraciones cuando deben cumplirse aun sin la interfaz. El frontend conserva la edición más reciente mediante revisiones locales; la IA recibe omisiones explícitas, devuelve observaciones verificables y sus agregados se recalculan en servidor. Las funciones Edge mantienen autenticación previa, límites de cuerpo y reintentos idempotentes con vencimiento.

**Tech Stack:** React 18, TypeScript, Vitest, Supabase/PostgreSQL, Supabase Edge Functions.

**Spec:** `docs/AUDITORIA_INTEGRAL_2026-09-08.md`

## Global Constraints

- No enviar retroalimentación automática al estudiante.
- Cada evaluación del lote sigue siendo independiente por estudiante y provisional hasta revisión docente.
- Conservar la respuesta original y no inventar puntuación para preguntas omitidas.
- Mantener el máximo de 50 estudiantes significativos por importación.
- No desplegar ni publicar sin autorización separada.
- Ejecutar cada corrección con ciclo RED–GREEN y terminar con `npm run verify` y React Doctor.
